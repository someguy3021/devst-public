# Фича 10: Код-интеллект — clean-room сборка (граф зависимостей, blast radius, здоровье)

> Русский · [English](../../features/10-code-intelligence-clean-room.md)

> **Статус:** Реализовано (первый срез: каскада парсеров, импорт-граф, blast radius,
> git-аналитика, health, UI-панель, MCP-инструменты) · **Обновлено:** 2026-10-10

**Суть:** у devst появляется второй столб контекста для агента рядом с каноном:
индекс кода в отдельном `graph.db` — импорты и символы, blast-radius диффа,
git-аналитика (churn, hotspots, ownership), health-находки с очередью fix-first,
кандидаты в мёртвый код с уровнями уверенности. Каждый ответ выдаётся через
MCP-инструменты ([фича 08](./08-mcp-server.md)) и дашборды Tauri-окна
([фича 03](./03-devst-ui-desktop-window.md)), с `_meta`-честностью: свежесть,
полнота и приближения называются, а не прячутся. Дизайн — clean-room по идеям
[repowise](https://github.com/repowise-dev/repowise) — публичного AGPL-проекта
код-интеллекта: читаем их доки и наблюдаемое поведение CLI, но не код; имена,
форматы и архитектура — наши.

**Ключевые факты:**

- идеи легальны, код — нет: AGPL защищает код и тексты, но не идеи и алгоритмы;
  каждая взятая идея фиксируется строкой наследования «идея → их док → наш модуль»;
- zero runtime-deps: парсеры каскады вендорятся в бинарь через ассет-манифест
  (`pnpm vendor`), ~9 МБ суммарно с `typescript.js`;
- отдельный `graph.db` — пересобираемый и сбрасываемый; канон-реестр задач
  не затрагивается ([ADR-017](../decisions/adr-017-hybrid-storage-md-sqlite.md));
- если в репе уже стоит repowise, devst его детектит и предлагает выключить наши
  пересекающиеся подсистемы — детект, не блокировка
  ([ADR-010](../decisions/adr-010-detect-dont-block.md)).

**Связанное:** [repowise](https://github.com/repowise-dev/repowise) (каталог идей;
атрибуция и благодарность) ·
[ADR-028](../decisions/adr-028-parser-cascade-t0-t1-t2.md) (каскада парсеров) ·
[фича 08](./08-mcp-server.md) (get_context / get_risk / get_blast_radius /
get_overview) · [фича 03](./03-devst-ui-desktop-window.md) (панель
код-интеллекта) · [ADR-017](../decisions/adr-017-hybrid-storage-md-sqlite.md)
(отдельный индекс-DB) ·

## Сценарии

1. **Кодит маленькая локальная модель** — агент запрашивает
   `get_context(файл)` и получает триаж-карточку (сигнатуры, импортеры, churn,
   владелец) в бюджете символов; после правки — `get_blast_radius(дифф)`: что
   задето и какие тесты гонять. Карта репы выдаётся готовой, а не строится
   дорогим перебором.
2. **Человек открывает окно** — панель код-интеллекта показывает карту
   зависимостей, hotspots и очередь fix-first (health × hotspot); клик —
   досье файла с планом рефакторинга.
3. **Смертный час: чистка** — dead-экспорты и недостижимый код с уровнями
   уверенности; `safe_to_delete` — только выше высокого порога (≥ 0.7 — их
   культура честных «rows we lose» становится нашей бенчмарк-честностью).
4. **Сосед repowise** — маркеры `.repowise/` детектятся в `devst env`/`doctor`:
   «обнаружен repowise; можно выключить наши пересекающиеся подсистемы, чтобы
   не мешать». Решение — за автором репы
   ([ADR-010](../decisions/adr-010-detect-dont-block.md)).

## Каскада парсеров: T0 / T1 / T2, семейство слотов

Тиры достраивают друг друга; происхождение каждого факта маркируется,
confidence рёбер растёт с уровнем тира, апгрейд точности не ломает индекс
([ADR-028](../decisions/adr-028-parser-cascade-t0-t1-t2.md)). T2 сознательно —
**семейство слотов по языкам**, а не один парсер.

| Тир | Роль | Состав / когда работает | Честность |
|---|---|---|---|
| **T0 — свой сканер** | база и фоллбек **всех языков**: импорты/экспорты регэкспами + скобочный скан | всегда; без него — ничего | низкий confidence, пометка «приближение» |
| **T1 — LSP-мост** | основа точности TS/JS: tsserver из node_modules целевой репы | TS/JS, сервер доступен | версия проекта = истина; таймаут/лежит → фолбэк на T0/T2 с пометкой в `_meta` |
| **T2 — вшитые парсеры (мультислот)** | автономная точность без процессов | TS/JS — `typescript.js` (~8 МБ) · Python/Go/Java/Rust/C/C++ — `@lezer/*` · PHP — `php-parser` · Lua — `luaparse` · Elixir — `lezer-elixir` — ~1 МБ сверху | **версионная честность**: ассет знает свою версию и видит версию проекта; расхождение или провал разбора = `parsed-with-mismatch`/`unparsed` в `_meta`, не тихий пропуск |
| **T2-WASM — отложенный подслот** | расширение набора: C#, Kotlin, Swift, Dart, Scala… через `web-tree-sitter` | только после ручной проверки instantiate-из-ассета в реальном SEA-бинаре | статусы T2 + пометка «экспериментальный слот» |

Порядок дружбы: T0 строит индекс всегда (дёшево, все языки, ненадёжность
маркирована); для каждого языка берётся лучший доступный слот — T1 (TS/JS,
версия проекта) > слот T2 > T0. Ассет-манифест (`engines-meta.ts`) несёт
слот/язык/пакет/версию/лицензию/размер; нотисы BSD-3 и Apache-2.0 едут копиями
вместе с ассетами.

## Clean-room дисциплина

- Их **код не открываем** для переноса; источники идей — публичные доки
  (README, architecture, бенчмарки) и наблюдаемое поведение CLI.
- Дословные тексты не копируем; имена подсистем и инструментов — свои
  (`devst analyze`, `get_*` — общий жанр MCP).
- Каждая идея — строка наследования «идея → их док → наш модуль»
  (LINEAGE-принцип, взятый из их же практики).
- Бенчмарк-честность как ориентир: наши приближения публикуем с числами,
  включая проигрыши.
- Памятка AGPL: идеи, алгоритмы и факты не лицензируются; код и тексты —
  лицензируются. Сомневаешься в конкретном фрагменте — не брать, переизобрести.

## Не делаем

- Не векторная БД, не LLM-провайдеры, не serve-демон: детерминированные слои
  работают без модели — офлайн-принцип.
- Не «все 26 языков сразу»: точный набор слотов — TS/JS + Python/Go/Java/Rust/
  C/C++/PHP/Lua/Elixir; прочие языки едут на T0; расширение набора — через
  ассет-манифест (WASM-подслот — после SEA-проверки).
- Не замена канона: код-интеллект — второй столб контекста; доки, реестр и
  ритуалы остаются ядром devst.
