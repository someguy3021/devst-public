# Feature 07: Связанные репы — канон соседа, его логи и зеркала

> Русский · [English](../../features/07-linked-repos.md)

> **Статус:** Реализовано (v1.2) · **Обновлено:** 2026-10-06

**Суть:** раздельные devst-репы декларируют друг друга в `docs/links.json`; документы
связуются ссылками `id://путь/док.md` (линтер проверяет), знания — пинами sha256+HEAD,
история — зеркалами избранных логов. Сценарий-якорь: внешний TTRPG-проект (потребитель
ИИ-ассетов) ↔ его сосед-база знаний; в самой devst соседом заявлена репа внутренней
методологии (dev-standard).

**Ключевые факты:**

- сосед объявляет нас у себя (взаимность проверяется);
- сосед не пишется никогда;
- сосед может быть не devst (деградация до git + хешей);
- отчёты не блокируют.

**Связанное:** [ADR-025](../../decisions/adr-025-linked-repos-links-json.md) (манифест, ссылки `id://`) ·
[фича 05](./05-reminder-system.md) (детектор links-stale) ·
[ADR-020](../../decisions/adr-020-tauri-sidecar.md) (вкладка едет на CLI-сайдкаре) ·
§5.8 стандарта · `devst links --help`

## Сценарии

1. **«Что сосед делал, пока я не смотрел?»** — `devst links check`: тезисы последних
   сессий соседа (имя файла + Суть из шапки), его коммиты с даты моего пина,
   HEAD и dirty-счётчик.
2. **«Запиненное мной ещё актуально?»** — `links pin` запоминает sha256 запиненного
   каталога соседа; `links check` отвечает `ок / ИЗМЕНИЛОСЬ с 2026-10-06 / ПРОПАЛО`.
3. **«У меня в доке ссылка на материал соседа»** — маркдаун-ссылка вида:

   ```markdown
   [выводы тестов](std://docs/checklists/testing.md)
   ```
   линтится как внутренняя ссылка: сосед не заявлен или файл исчез — ошибка `ссылка-сосед`.
4. **«Утеря репы не должна потерять историю сессий»** — зеркалирующая сторона держит
   секцию `mirror` (regex по именам файлов) в своём манифесте; `devst links mirror`
   кладёт байт-в-байт копии в свой `docs/mirror/<id-соседа>/`; `links check` показывает
   «свежее / отстало».

## Манифест `docs/links.json`

```json
{
  "version": 1,
  "neighbors": [
    {
      "id": "std", "name": "dev-standard",
      "path": "../dev-standard", "role": "producer",
      "note": "канон внутренней методологии",
      "pins": [ { "id": "std-docs", "target": "docs/" } ],
      "mirror": [ { "id": "session-logs", "source": "docs/log/",
                    "match": "^2026-10.*session.*\\.md$" } ]
    }
  ]
}
```

Правила: id — `[a-z][\w-]*`, уникальный; path — относительный от корня
(машинно-независимо); role — роль **соседа** относительно нас; хеши/даты/HEAD
дописывает `links pin`. `match` — regex по имени файла; `into` — необязательный
каталог копий (по умолчанию `docs/mirror/<id>/`).

## Правила безопасности

- Команды пишут только в свою репу: `pin` — свой манифест, `mirror` — свой
  `docs/mirror/`. Сосед читается (`fs`, `git --no-pager`), но не изменяется —
  безопасно при работающих у него агентах.
- Хеши каталогов: Merkle по отсортированным относительным путям, исключая
  `node_modules/`, `__pycache__/`, `.git/`, `*.log`, `*.pyc`.
- Не-git сосед: HEAD/логи сессий/взаимность отсутствуют — пины и проверка
  существования работают.

## Не делаем

- Ничего не мутируем у соседа (нет «push зеркала» в чужую репу).
- `links check` не входит в `devst check` и ничего не блокирует (v1); `--strict` — при нужде.
- Автоскан «всех реп рядом» — соседей заявляет человек (`devst env` подсказывает кандидатов).

## v1.1 — замыкание ритуала (напоминания)

Протухшие связи сами приходят в SessionStart: remind-детектор `links-stale`
([фича 05](./05-reminder-system.md)) считает проблемы соседей — репа не найдена,
связь не взаимна, пин ИЗМЕНИЛОСЬ/ПРОПАЛО, зеркало отстало/не скопировано — и зовёт
`devst links check`. Отключается строкой `links-stale` в `remind.off` конфига devst.json.

## v1.2 — вкладка «Соседи» в devst-ui

Панель `NeighborsPanel` (вкладка `hub`, бейдж с числом проблем): отчёт
`links check --json` через CLI-сайдкар (как remind, [ADR-020](../../decisions/adr-020-tauri-sidecar.md)) —
статус соседа (devst / не devst / НЕ НАЙДЕНА), взаимность, HEAD и dirty-счётчик,
тезисы логов соседа, его коммиты, пины и зеркала. Кнопки «Проверить / Перепинить /
Зеркала» зовут CLI — пишут только в свою репу, соседа не трогают. Контракт UI ↔ CLI —
локальная копия формы отчёта в `kernel/adapter.ts` (прецедент RegistryTask; tsconfig UI
не тянет node-модули). Тексты — словари RU/EN (T-26). Тесты: `tests/ui-links-panel.test.ts`
(чистое view: счётчики проблем, kinds, обрезка) + ui-e2e «Соседи» (панель из
сайдкар-фикстуры, бейдж 2→1→0 по кнопкам, пустое состояние без манифеста).
