# ADR-002: Скилл для агентов с приоритетным сценарием «дока уже есть»

> Русский · [English](../../decisions/adr-002-skill-for-agents.md)

> **Статус:** принято · **Дата:** 2026-09-06

**Суть:** SKILL.md — компактная выжимка-маршрутизатор с тремя сценариями (А: доки ещё нет /
Б: апгрейд существующей / В: рабочий цикл); главный — Б.

**Отвергнуто:** тонкая обёртка над CLI (слишком узко); пересказ всего стандарта
(дубль источника истины).

**Связанное:** `skill/SKILL.md` · [ADR-003](adr-003-harness-integrations.md)

## Контекст

Репа опубликована на GitHub, а домашние проекты автора ведут доку по старым форматам
методологии — скилл обязан покрывать апгрейд, а не только greenfield-развёртывание.

## Решение

SKILL.md несёт три сценария плюс инварианты; полный текст стандарта остаётся во внутренней
методологии dev-standard и упоминается ссылкой, никогда не копируется. Канон скилла живёт
в репе, установленная копия — в `~/.agents/skills/devst`.

## Последствия

При каждом изменении обновлять оба места. Сценарий Б (обновить шапки, карту и панель
«Сейчас», не переписывая устоявшиеся смыслы) проверен боем на внешнем TTRPG-проекте.
