# ADR-011: Реестр верстки ui-freeze — знание + гард + diff-анализ

> Русский · [English](../../decisions/adr-011-ui-freeze.md)

> **Статус:** принято · **Дата:** 2026-09-08

**Суть:** `docs/ui-freeze.md` (таблица экран → статус → области) + три механизма: SessionStart-инъекция, PostToolUse-гард на любой файл, pre-commit разбор staged diff. Два уровня: 🔒🔒 жёстко (программный запрет) и 🔒 мягко (можно править под ворнингом).

**Отвергнуто:** тотальное правило «запретить правку файла» — слишком грубо. Основной стек автора — Vue SFC: `<script>`-блок замороженного экрана обязан оставаться редактируемым, поэтому заморозка на уровне файла без гранулярности по блокам убивает легальные правки логики.

**Связанное:** [ADR-010](adr-010-detect-dont-block.md) · dev-standard v1.3 · figma-dump

## Контекст

Требования автора (утверждены через вопросы): защита на уровне блоков (`.vue`), файлов и папок-glob с исключениями; два уровня запрета — программный и мягкий; таблица живёт в `docs/ui-freeze.md`; diff-анализ с первого дня; 🔒🔒 = «программно запретить трогать файл или блок». E2E этот класс проблем не ловит: кнопка есть, но не та, не там, или макет чужой ревизии.

## Решение

1. **Модель:** статусы 🔒🔒 / 🔒 / ❓ / 🔨 / ♻; области — `файл.vue (template,style)`, файл/папка glob, `!исключения`; «Макет» — фрейм figma-dump + версия дампа (заморозка относительно ревизии; расхождение `check`/`diff` дампа — сигнал пересверки).
2. **CLI `freeze`:** список / `--file` (вердикт, питает PostToolUse) / `--staged` (staged diff `-U0`: хунки ∩ блоки SFC; full-области срабатывают на любое изменение).
3. **Хуки:** SessionStart — строка-сводка «N 🔒🔒 + M 🔒»; PostToolUse — мгновенное сообщение агенту при правке защищённого файла (для 🔒🔒: «отмени и спроси»); pre-commit (warn по умолчанию, `--strict` блокирует жёсткие нарушения).
4. **Линт:** шапка доки ui-freeze.md + `freeze-без-файлов` (строка 🔒🔒/🔒 без областей — ошибка: гейту нечего защищать).

## Примечание реализации

Канон статусов — СЛОВА (жёстко/мягко/спросить/не сделано/свободно); эмодзи в колонке — только декор: байты эмодзи капризны к транспортам окружения (grep внутри хуков в части сценариев их не видел). Хуки считают статусы по словам.

## Последствия

Опциональность by design: без `docs/ui-freeze.md` вся механика молчит. Чистые удаления файлов (hunk count = 0) детектятся лишь приближённо; ограничение принято.
