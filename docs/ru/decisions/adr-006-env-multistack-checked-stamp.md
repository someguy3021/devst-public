# ADR-006: `devst env` (мультистек) + пометка «Проверено» со событийной свежестью

> Русский · [English](../../decisions/adr-006-env-multistack-checked-stamp.md)

> **Статус:** принято · **Дата:** 2026-09-08

**Суть:** механическая разведка окружения (манифесты node/php/go/rust/python/make,
Make-цели, compose, соседние проекты, CI), которая драфтит таблицу окружения;
свежесть отслеживается событийно — по mtime или последнему коммиту.

**Отвергнуто:** разведка только текстовым протоколом скилла; календарный таймер проверки.

**Связанное:** [ADR-005](adr-005-env-in-l0.md) · [ADR-007](adr-007-review-fixes.md)

## Контекст

Вопросы автора: на каких стеках это сработает (до этого — только package.json); как
устроена сама разведка; есть ли «когда проверяли последний раз» и «как часто» (не было).

## Решение

(1) Команда `env` со стек-агностичным сканом, которая драфтит таблицу; (2) правило
`env-e2e` ищет e2e-упоминание в тексте каждого манифеста; (3) пометка
`_Проверено: дата_` плюс линт-правило `env-freshness`. Политика частоты — событийная
(манифест изменился), календарный максимум — квартал.

## Последствия

Ограничение: CLI требует Node ≥ 18. Команды `env` — эвристики-драфт; истина — ручная
проверка.
