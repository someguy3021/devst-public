# ADR-003: Интеграции харнесса — slash-команды и два хука (якорь file_path)

> Русский · [English](../../decisions/adr-003-harness-integrations.md)

> **Статус:** принято · **Дата:** 2026-09-06

**Суть:** команды `/session` и `/docs-upgrade` плюс SessionStart-инъекция состояния и
PostToolUse-линт доков; хуки якорятся на `file_path` из payload, а не на cwd.

**Отвергнуто:** гард по cwd — хуки стартуют из собственного рабочего каталога харнесса
и молча но-опятся (подтверждено мёртвыми CRG-хуками автора).

**Связанное:** `integrations/zcode/` · [ADR-008](adr-008-standard-version-tracking.md)

## Контекст

Скилл добровольный; ритуалам документации нужны детерминированные точки входа и контроль
в момент правки. ZCode (AI-харнесс) даёт для того и другого slash-команды и хуки.

## Решение

Slash-команды `/session` и `/docs-upgrade`; SessionStart — «есть каталог `docs/` →
активироваться автоматом» (панель «Сейчас» плюс протокол сессии); PostToolUse —
линт-на-сохранение с подъёмом от `file_path` до ближайшего корня с `docs/`.
CRG post-tool-use хук переведён на тот же якорь.

## Последствия

**Ключевой урок экосистемы:** payload хука обязан парсить Python-ом прямо из stdin —
любой проход байтов через bash-транспорт Git Bash портит escape-последовательности
(`\\a` → BEL). Конфигурация — пользовательская (`~/.zcode/cli/config.json`); канон
скриптов — в этой репе.
