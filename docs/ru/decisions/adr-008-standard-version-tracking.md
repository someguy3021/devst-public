# ADR-008: Трекинг версии стандарта + SessionStart как ловец правок «без тулзы»

> Русский · [English](../../decisions/adr-008-standard-version-tracking.md)

> **Статус:** принято · **Дата:** 2026-09-08

**Суть:** `check` парсит версию стандарта из шапки док-файла docs/README и
предупреждает, когда проект отстаёт; SessionStart-хук гоняет check и вплетает его
находки в утреннюю инъекцию.

**Отвергнуто:** отдельное поле/файл версии (в шапке док-файла для него уже есть место).

**Связанное:** [ADR-003](adr-003-harness-integrations.md) · dev-standard v1.2

## Контекст

Ревизия слабостей: (7) проект не знал, что отстал от новой версии стандарта; (1)
правки доков вне ZCode не линтил никто — первое автор оценил как более важное.

## Решение

Правила `standard-version` / `standard-outdated` сверяются с `STANDARD_VERSION` CLI;
SessionStart-хук добавляет к инъекции сводку ошибок/предупреждений check. Слои 2–3
ловли правок (pre-commit, GitHub Action) остаются в роадмапе.

## Последствия

Каждый подъём версии стандарта запускает по проектам волну «обновись сейчас» — это
фича. Живой пример: внешний TTRPG-проект на v1.1 получил честное предупреждение.
