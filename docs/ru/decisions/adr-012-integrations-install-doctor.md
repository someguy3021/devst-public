# ADR-012: Integrations install / doctor (этап 1); запуск из чекаута репы явно помечен временным

> Русский · [English](../../decisions/adr-012-integrations-install-doctor.md)

> **Статус:** принято · **Дата:** 2026-09-08

**Суть:** `devst integrations install [--only …]` раскладывает скилл, команды, хуки и конфиг по местам харнесса (таргет-спеки в `integrations/targets/*.json`; этап 1 — ZCode); `devst doctor` проверяет всю цепочку и ловит дрейф установленных копий. Запуск CLI нодой из папки репы явно помечен как ВРЕМЕННЫЙ вариант (этап 0 дистрибуции).

**Отвергнуто:** «форк под каждый харнесс» — заменён тремя слоями переносимости (истина / знания / принуждение) с git pre-commit как переносимым enforcement-слоем; также отвергнута установка без doctor (пять поверхностей разъехались бы).

**Связанное:** [ADR-003](adr-003-harness-integrations.md)

## Контекст

Пять поверхностей установки копировались руками и расходились с каноном; в хуки вшит абсолютный путь CLI, ломающийся при переезде репы; пользователь может думать, что тулза «установлена» как npm-пакет, а она запускается нодой прямо из папки репы.

## Решение

1. **Таргет-спеки** (JSON): плейсхолдеры `{home}`/`{zcode}` с дефолтами, флаг `--zcode` и env-переменная `DEVST_HOME`; `--only skill|commands|hooks|config` (выборочность — явное требование автора).
2. **install:** копии канона; в хуки прошивается актуальный путь CLI (`patchHookDefault`); конфиг мержится идемпотентно (без дублей событий, бэкап `.bak-devst`); метка `{zcode}/devst.json` (репа + CLI + дата) — задел под дистрибуцию npm/бинарником, когда CLI сможет жить отдельно от репы.
3. **doctor:** окружение (node/git/python), наличие dist, хэш-сверка установленных копий с каноном (missing/drift), регистрация конфига, smoke-прогоны синтетических payload через УСТАНОВЛЕННЫЕ хуки (валидный JSON). Дрейф лечится повторным install.
4. **Временность:** README/HELP прямо говорят «нода из папки репы — этап 0»; финал — npm/бинарник, связано с сайдкаром Tauri-UI.

## Последствия

Догфуд: настоящий install разложил 10 артефактов; doctor отчитался 8✅/0✖; искусственно устроенный дрейф (правка копии скилла) пойман и вылечен `install --only skill`. Контрактные тесты хуков (`tests/hooks.test.ts`) закрепляют payload-формы ZCode — целый класс транспортных багов теперь ловится `pnpm test`, а не в бою.
