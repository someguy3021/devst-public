# ADR-027: devst new research — скаффолд разведок

> Русский · [English](../../decisions/adr-027-new-research-scaffold.md)

> **Статус:** принято · **Дата:** 2026-10-07

**Суть:** `devst new research "тема"` создаёт стаб разведки `research/дата-слаг.md`
(YYYY-MM-DD + слаг темы); разведки больше не заводятся вручную. Уточняет
[ADR-026](adr-026-research-section.md) (его оговорка «не скаффолдит, если
понадобится — отдельная задача» исполнена).

**Отвергнуто:** отдельная нумерация разведок (как у ADR/фич) — не нужна: имя
разведки = дата-слаг, коллизии честно ловятся отказом «файл уже существует».

**Связанное:** [ADR-026](adr-026-research-section.md) ·
репа внутренней методологии (dev-standard): версионный футер v1.9

## Контекст

- [ADR-026](adr-026-research-section.md) сделал research/ полноправной секцией
  (map/check/досье), но скаффолд не добавил — разведки создавались копированием
  существующих.
- Решение автора (чат 2026-10-07): «Да, давай devst new research сделаем».
- Правило канона: команды CLI менялись → синхронно скилл/README/TOOLING репы
  внутренней методологии (dev-standard) + версионный футер стандарта
  (v1.8 → v1.9) + STANDARD_VERSION.

## Решение

**Вариант — research в `NewKind`/`NEW_KINDS` (src/scaffold.ts).** Стаб: шапка
разведки (Статус: разведка · Обновлено · Суть · Связанное, ≤ 20 строк) + секции
«Находки» и «Вердикт» — по образцу существующих разведок репы. Init-карта T2/T3
(readmeGenerated) теперь генерирует секцию `research/` с подсказкой команды.

Попутная гигиена той же правки:

- `runNew` валидирует вид по `NEW_KINDS`: неизвестный вид — громкая ошибка
  (раньше молча создавался roadmap-стаб, П1/П3-стиль из отчёта миграции внешнего
  TTRPG-проекта).
- Help-строка CLI несла протухшую «dev-standard v1.6» — теперь динамически
  `${STANDARD_VERSION}`.
- `STANDARD_VERSION` 1.8 → 1.9 (синхронно с футером соседа).

## Обоснование

- Единый честный способ заводить доки (правило «никаких самодельных номеров»)
  распространяется на разведки; стаб несёт конвенцию шапки сразу.
- Валидация вида закрывает тихий путь «опечатка в виде → файл не в той секции».

## Последствия

**Позитивные:**

- Разведка с конвентной шапкой — одной командой; init-репы получают секцию в карте
  сразу, map-сироты с первого дня попадают куда надо.

**Негативные / риски:**

- Повторный `new research` с той же темой в тот же день — отказ «файл уже
  существует» (осознанно, как у остальных видов без номеров).
- Репы на старой карте без секции research/ получат подсказку «нет секции —
  добавь вручную» при первой разведке (drift, не ошибка).
