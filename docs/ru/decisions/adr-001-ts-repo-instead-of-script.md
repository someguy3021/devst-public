# ADR-001: TS-репозиторий с чистым ядром вместо одного скрипта

> Русский · [English](../../decisions/adr-001-ts-repo-instead-of-script.md)

> **Статус:** принято · **Дата:** 2026-09-06

**Суть:** devst — TypeScript-репа (чистое ядро + тонкий CLI + vitest), не однофайловый скрипт.

**Отвергнуто:** оставить `devst.mjs` (монолит без тестов); фреймворк-CLI с зависимостями.

**Связанное:** обзор архитектуры (`docs/architecture/01-overview.md`) · сессия 0 (до T2-миграции)

## Контекст

`devst.mjs` вырос из быстрого одноразового скрипта в настоящий инструмент, и автор хочет
его расширять — в перспективе перенеся графовые инструменты с Python на TypeScript.

## Опции

- **Оставить скрипт** — просто, но монолит без тестов; расширять рискованно.
- **CLI-фреймворк (commander и т.п.)** — зависимости ради зависимостей.
- **TS-репа с чистым ядром** — ядро — чистые функции над строками и списками имён;
  доступ к ФС — только в тонком `cli.ts`.

## Решение

**TS-репа:** чистое ядро + тонкий `cli.ts`; тесты на vitest; strict `tsc`;
ноль runtime-зависимостей.

## Последствия

**Позитивные:** тестируемость; расширяемость под будущие модули (включая графовые инструменты).
**Негативные:** перед использованием CLI нужен `pnpm build` (`dist/cli.js`).
