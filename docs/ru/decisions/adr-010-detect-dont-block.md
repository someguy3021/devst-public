# ADR-010: Правки без тулзы — детектить, не блокировать

> Русский · [English](../../decisions/adr-010-detect-dont-block.md)

> **Статус:** принято · **Дата:** 2026-09-08

**Суть:** `devst undocumented` находит коммиты кода новее последней записи в
docs/log/ и говорит агенту «разберись и запиши»; pre-commit по умолчанию
предупреждает, блокировка — opt-in через `--strict`.

**Отвергнуто:** блокирующий pre-commit по умолчанию (автор: мои собственные
коммиты, сделанные без тулзы, не должны застревать); напоминания по календарю
(событийный подход точнее).

**Связанное:** [ADR-008](adr-008-standard-version-tracking.md) · [ADR-003](adr-003-harness-integrations.md)

## Контекст

Требование автора: «я поменял штуку, не записал и без агента не запишу,
закоммитил и залил — тулза должна сама узнать факт и сказать агенту это записать;
блокировать мои коммиты по умолчанию не хочется».

## Решение

1. **`devst undocumented`:** граница задокументированного = последний хэш,
   упомянутый в docs/log/; недокументированные = коммиты КОДА/конфигов новее
   границы. Правки docs/, README.md, AGENTS.md из обхода исключены — закрывающий
   docs-коммит сессии не висит хвостом вечно, и протокол остаётся
   самосогласованным: работа → код-коммит → запись в log с хэшем → docs-коммит.
2. **SessionStart-хук** добавляет строку «⚠ N коммитов без записи в log/
   (хэш тема) — разберись и запиши (/session)».
3. **Pre-commit warn-by-default:** ошибки check уходят в stderr, коммит проходит;
   `--strict` ставит блокирующий вариант. Существующие установки не трогаются
   (при желании переустановить вручную).

## Последствия

Слои ловли правок: (1) SessionStart check + undocumented — накопленный дрейф
всплывает в первом же чате; (2) pre-commit warn/strict — в момент коммита;
(3) GitHub Action — правки, приходящие извне (web-UI); остаётся открытым вопросом.
